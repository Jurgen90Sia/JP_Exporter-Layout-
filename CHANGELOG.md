# Changelog

## 0.2.0 — Unreleased development

- Preserve original wireframe pipeline and add orthonormal isometric projection.
- Add optional opaque-triangle visible/hidden interval processing and dashed preview.
- Add orthographic overall dimension graphics with paper-mm annotation sizing.
- Connect DXF R2000 LINE/TEXT export and validated portable drawing snapshots.
- Add explicit file-command registry, framing reset and failure-safe file operations.
- Normalize packaging manifests on Windows; report unavailable symlink privilege.
- Add research/audit evidence and regression tests, including edge-on and large-coordinate occlusion cases.

Native LayOut/PDF, sections, associative dimensions and full projects remain unimplemented.
No production compatibility or complete LU parity is asserted.

## 0.1.0 — Unreleased

- Register an isolated SketchUp extension and HtmlDialog preview command.
- Extract selected geometry with nested instance transforms and millimeter units.
- Project six orthographic wireframe views and render SVG previews.
- Add geometry, host contract and JavaScript tests, CI and package validation.
- Specify document, section, dimension, hidden-line and export architecture.

No SketchUp runtime compatibility or production release is asserted.
